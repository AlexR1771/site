# Инструменты


Здесь удобно описывать программы, шаблоны, таблицы и внутренние чек-листы, которые помогают в ежедневной работе.

Например:

- шаблоны расчётов;
- внутренние таблицы;
- чек-листы проверки проекта;
- быстрые ссылки на нормативы;
- заметки по оформлению документации.

Смысл этой страницы — держать рядом всё, что ускоряет повторяющиеся операции и не даёт терять время на поиск одинаковых вещей в разных папках.
